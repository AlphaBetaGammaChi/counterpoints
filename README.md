# Counterpoints

A collection of evidence-backed rebuttals and discussion documents for contested
topics. Each topic gets a directory under `topics/` containing:

- **`index.md`** — landing page / TL;DR
- **`evidence.md`** — the master scientific evidence review
- **`arguments/`** — one document per common claim, each containing:
  the claim as typically stated → short answer → evidence with citations →
  steelman/nuances → bottom line
- **`references.md`** — full bibliography (peer-reviewed first, grey literature second)
- **`advocacy.md`** — campaign groups, official programmes and further resources
- **`slides.md` / `slides.html`** — a presentation built from the same content
- **`figures/`** — generated charts and animations (see `scripts/`)

## Rules of the house

1. **Every claim is cited.** Peer-reviewed literature carries a DOI link; grey
   literature (government statistics, WHO, agency reports) carries a URL.
2. **Steelman before rebuttal.** Each document states the strongest reasonable
   version of the opposing claim before answering it.
3. **Plain language up front, technical detail below.** Every document opens
   with a short answer a lay reader can use, then provides the technical
   section for sceptics.
4. **Figures are reproducible.** Everything in `figures/` is generated by
   `scripts/` — no hand-edited charts.

## Publishing to GitHub Pages

This directory is a self-contained Jekyll site (`_config.yml` uses the
`jekyll-theme-cayman` theme). Push it to a GitHub repo and enable
**Settings → Pages → Deploy from branch → root**. All Markdown pages carry
front matter and will render automatically.

Regenerate figures:

```bash
/opt/anaconda3/bin/python3 scripts/make_woodsmoke_figures.py
```

Build the slide deck (requires Node):

```bash
npx -y @marp-team/marp-cli topics/woodsmoke/slides.md -o topics/woodsmoke/slides.html --allow-local-files
```
